# 🚀 VG+ | Visionary Growth - صندوق الرسائل التفاعلي

منصة تفاعلية حديثة تتيح للمستخدمين والزوّار إرسال رسائل واقتراحات وأفكار مجهولة وسرية إلى فريق **VG+ (Visionary Growth)**، مع إمكانية اختيار الأفاتار (شخصية تفاعلية)، وتصنيف نوع الرسالة، وحفظها في صندوق وارد مشفّر ومحمي برمز سري خاص.

---

## 🌟 المميزات الرئيسية
* **هوية بصرية رسمية لفريق VG+**: تصميم مستوحى من خطوط وألوان شعار Visionary Growth (الأخضر الزمردي والكحلي التقني).
* **اختيار الأفاتار والشخصية الرقمية**: 8 شخصيات متميزة مع مؤثرات صوتية وبصرية عند الاختيار.
* **تصنيف الرسائل (Tags)**: (فكرة واقتراح، مشروع ريادي، شكر وتقدير، سرية خاصة، استفسار).
* **مؤثرات تفاعلية حية**: ألعاب نارية واحتفال بـ Confetti عند نجاح الإرسال، مع نغمات صوتية تفاعلية.
* **صندوق الوارد المحمي (Private Inbox)**:
  - صفحة خاصة لصاحب الموقع لعرض كافة الرسائل الواردة.
  - قفل كامل برمز سري (PIN: `1234`).
  - تحديث تلقائي فوري كل 5 ثوانٍ للرسائل الجديدة بدون إعادة تحميل الصفحة.
  - إمكانية حذف الرسائل أو إفراغ الصندوق.

## 🛠️ كيفية التشغيل على جهازك عبر VS Code

1. افتح مجلد المشروع في **VS Code**:
   ```bash
   code .
   ```
2. افتح الـ Terminal الداخلي في VS Code (`Ctrl + ~`).
3. ثبّت الحزم (إن لم تكن مثبتة):
   ```bash
   npm install
   ```
4. شغّل الخادم:
   ```bash
   npm start
   ```
5. افتح الروابط في المتصفح:
   - **صفحة الزوّار:** `http://localhost:3000`
   - **صندوق الوارد:** `http://localhost:3000/inbox.html` (الرمز السري: `1234`)
